# ЛР-2

### для сборки сайта были использованы 

- **Node.js** среда выполнения
- **Vite** сборщик проекта
- **Sass** препроцессор CSS
- **Bootstrap 5** (частично, с переопределением стилей)

Для установки обновлений и зависимостей был использован менеджер пакетов npm

#### Установка и запуск:
```bash
npm install          # установка зависимостей
npm run dev          # запуск dev-сервера
```
